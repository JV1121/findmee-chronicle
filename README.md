## Deploying to GitHub Pages

1. Create a new repo on GitHub (public, any name — e.g. `findmee-chronicle`).
2. Upload the contents of this folder (`index.html` + the `assets/` folder) to the repo root.
3. Go to **Settings → Pages** in your repo.
4. Under **Source**, choose **Deploy from a branch**.
5. Pick **main** branch and **/ (root)** folder → **Save**.
6. Wait 1–2 minutes. Your site will be live at:
   `https://YOUR-USERNAME.github.io/YOUR-REPO/`

## Custom domain (optional)

If you own a domain like `story.hopeviara.com`:

1. In your repo's **Settings → Pages → Custom domain**, enter the domain.
2. In your DNS provider, add a `CNAME` record pointing your subdomain to `YOUR-USERNAME.github.io`.
3. GitHub will automatically issue an HTTPS certificate within a few minutes.
